# Project skills

## gsap-*

Vendored from [greensock/gsap-skills](https://github.com/greensock/gsap-skills) (MIT).
They teach coding agents correct GSAP usage: core tweens, timelines, ScrollTrigger,
plugins, utils, React, other frameworks and performance.

Installed folders:

- `gsap-core`
- `gsap-timeline`
- `gsap-scrolltrigger`
- `gsap-plugins`
- `gsap-utils`
- `gsap-react`
- `gsap-frameworks`
- `gsap-performance`

Update (manual, keeps the repo self-contained):

```bash
git clone --depth 1 https://github.com/greensock/gsap-skills.git /tmp/gsap-skills
cp -r /tmp/gsap-skills/skills/* .opencode/skills/
```

OpenCode discovers project skills from `.opencode/skills/<name>/SKILL.md`.
