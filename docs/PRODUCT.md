# Product Context

## Users
- Primary: Biên tập viên, Dịch thuật viên, Retoucher, Letterer (Nhóm bản địa hóa manga/comic/webtoon tại LinkStory)
- Secondary: Quản lý & Team Leader theo dõi tổng quan tiến độ các dự án
- Operating Context: Ứng dụng web nội bộ hỗ trợ quản lý dự án, theo dõi deadline hằng tuần, ghi nhận logtime tự động, thực hiện checklist bàn giao và lưu trữ tài nguyên đám mây.

## Capabilities
- **Dashboard Tiến độ**: Quản lý task theo 3 mốc thời gian (Tuần trước, Tuần này, Tuần sau) với thẻ tác phẩm trực quan.
- **Checklist 9 bước**: Chuẩn hóa quy trình giao nộp tác phẩm (Mikan, kiểm tra comment, Delivered status, thưởng kinh nghiệm thú cưng).
- **LSA Drive**: Hệ thống quản lý tệp tin đám mây nội bộ tích hợp Supabase Storage.
- **Logtime Báo cáo**: Đồng bộ tiến độ tự động vào Google Sheets.
- **Đồng hành & Giải trí**: Hệ thống thú cưng ảo (Virtual Pet) tích lũy XP khi hoàn thành task và Lofi Radio đồng bộ.

## Platform & Constraints
- Platform: Web (Desktop & Mobile responsive)
- Backend: Python Flask
- Frontend: Jinja2 HTML5, Vanilla CSS, Modern JavaScript ES6+
- Storage: Supabase Cloud Bucket & Google Sheets API
